# Trinx Bicycles Bhutan

Website for **Trinx bicycles**, sold by **Gangjung Traders** in Thimphu — built in **Astro 7 + Tailwind CSS 4** as a port of the YuDruk Bicycle design (`D:\yudrukbicycle`, Next.js): black / white / Trinx blue, Unbounded + Geist type, pill buttons, bordered product grids.

There is **no online payment**. Orders, service bookings and test rides are sent to the shop on **WhatsApp**; the contact form opens the visitor's email app.

## Run

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static site -> dist/
npm run preview
```

Node 22.12+.

## Where things live

| Path | What |
|---|---|
| `src/data/site.ts` | **WhatsApp number, phone, email, address, hours, socials** (placeholders!) |
| `src/data/bikes.ts` | **Real Trinx specs** from trinx.com (15 bikes) — generated by `node scripts/gen-bikes.mjs`; add your Nu. prices here |
| `src/data/shop.ts` | Parts & gear catalogue (sample data) |
| `src/data/home.ts` | Navigation, hero slides, tiles, sale end date, footer links |
| `src/data/{service,faq,terms,team,about}.ts` | Page content |
| `src/components/` | Header, footer, product card, gallery, tabs, home sections |
| `src/scripts/` | Vanilla-JS islands: cart (localStorage), shop filters, finder, gallery, forms… |
| `src/assets/photos/` | Stock photos (Unsplash, by id) used by the data files |
| `src/assets/logo.jpg` | Gangjung Traders seal (header + footer) |

## Placeholders to replace before launch

- **Everything in `site.ts`** — the WhatsApp number, phone, email and address are fake.
- **Bike prices**: trinx.com publishes no prices (or weights), so every bike shows **Price on request** with an "Ask for price on WhatsApp" button. Set `price: { nu: 42500 }` in `bikes.ts` (or in `gen-bikes.mjs`) to switch a bike to normal pricing with Add to cart. Stock is a placeholder (all in stock).
- **Bike photos** are still illustrative stock images; replace with real product photos.
- Parts & gear products, service prices, team members, FAQ and Terms are placeholder content (Terms need legal review).
- Set `site` in `astro.config.mjs` and `SITE_URL` in `site.ts` to the live domain.
- `SALE_ENDS_AT` in `home.ts` controls the "On Sale" countdown.
