# CLAUDE.md — Trinx Bicycles Bhutan

Working notes for this project, saved from the build conversation (14 Oct 2026). Read this first when continuing the work.

## What this is

Website for **Trinx bicycles**, sold by **Gangjung Traders** (Thimphu, Bhutan). **Astro 7 + Tailwind CSS 4**, static output, vanilla-JS islands (no framework).
It is a port of the **YuDruk Bicycle** design (`D:\yudrukbicycle`, a Next.js shop for Trek bikes). Same layout, tokens and page set; content replaced for Trinx.

No online payment: orders, bike enquiries, service bookings and test rides go to the shop on **WhatsApp**; the contact form opens the visitor's email app.

## Commands

```bash
npm install
npm run dev        # http://localhost:4321  (during the session it ran on :4500)
npm run build      # must pass (65 pages) before handing work over
npm run preview
```

If the dev server shows stale CSS/images after adding files or images, restart it (and hard-reload the browser: Ctrl+Shift+R).

## Design system (src/styles/global.css)

- Accent colour: **`#0078b8`** (`--color-accent`), a deeper Trinx blue chosen so white text passes WCAG AA; the official trinx.com blue is `#0094de`. It was orange `#ff4e00` (YuDruk) until changed on request. White-on-blue small text is ~3.2:1 contrast (a deeper `#0078b8` would pass AA, but the official colour was requested).
- Fonts: Unbounded (headings, most text) + Geist (body), via Fontsource.
- Type scale `t-h1…t-h5`, `eyebrow`, `t-body`; layout `container-x`, `section-y`; buttons `btn`, `btn-primary`, `btn-outline`.
- Tailwind note: custom `@utility btn` has `display:inline-flex`; use `lg:!hidden` if a `.btn` must hide at a breakpoint.
- Scroll reveal: `.reveal` (+ `data-from="left|right"`), set up in `src/scripts/ui.ts`; disabled under `prefers-reduced-motion`.

## Data status — what is real and what is placeholder

- **Bikes (`src/data/bikes.ts`, 15)**: **real Trinx specs** from the official site `trinx.com` (14 Oct 2026): X9 Pro, X5 Pro, K036 Elite (Striker); Tempo 1.0, Tempo 2.1, TDO 900; GTR 2.0, Climber 2.3, Climber 2.1; Free 1.0, Touring 1.0 (700C), Cute 2.0; Red Elf 3.0, Blue Elf 3.0, Junior 4.0. Each has a `sourceUrl`. Generated by `node scripts/gen-bikes.mjs` (edit the script or the generated file).
  - trinx.com lists **no prices or weights** → `price.nu` is `null` → shown as **"Price on request"** with an "Ask for price on WhatsApp" button (no cart). Set `price: { nu: 42500 }` to switch a bike to normal pricing. Price filters/sort/finder budget handle null prices (budget question is hidden until prices exist).
  - Categories: Mountain, Road, Gravel, **City** (was Hybrid), Kids. Climber/GTR are listed under "Road" on trinx.com but classed as Gravel here (wide tyres / GRX parts). Inch frame sizes are mapped to S/M/L so the Bike Finder can match riders (our mapping, not Trinx's).
  - Trinx also sells full-suspension and e-bikes — not added.
  - `inStock` is a placeholder (all true).
- **Bike photos**: still illustrative stock images (user chose to keep them for now). The three hero bikes use the user's own official product shots (see below).
- **`src/data/site.ts`**: WhatsApp number (`97517000000`), phone, email (`info@gangjungtraders.example`), address (Thimphu) are **fake placeholders**. YuDruk's real number was deliberately NOT reused.
- Parts & gear (`shop.ts`, brands "Trinx" / "Gangjung Gear"), service prices, team members, FAQ, Terms are adapted placeholder content (Terms need legal review).
- Domain: `astro.config.mjs` `site` and `SITE_URL` in `site.ts` are `trinx.example.com`.
- `SALE_ENDS_AT` in `home.ts` controls the "On Sale" countdown (31 Dec 2026).

## Home hero (HeroSlider.astro)

Implements the user's spec: 3-column desktop layout (text / big bike PNG / thumbnail), huge faint watermark word, edge arrow buttons, "01 02 03" pagination, autoplay 6 s (pauses on hover / hidden tab / off-screen), ← → keys, touch swipe, `prefers-reduced-motion` respected, tablet hides thumbnail, mobile stacks. Vanilla JS, no libraries. Uses the site accent colour (blue) instead of the spec's `#FF4E00`.
- The home page uses the **solid white header** (`variant="solid"`) because the hero is white.
- Bike images: `bike-1` = X5 Pro (hardtail), `bike-2` = Tempo 2.1 (road), `bike-3` = K036 Elite (action). They are cut-outs made from the user's official studio shots in `src/assets/photos/` (`X5 Pro.jpg`, `Tempo 2.1.jpg`, `K036 Elite.jpg`, ~545 px wide) by `node scripts/cutout-bikes.mjs` (removes white background, wheel gaps and caption text; upscales 2x). **Source images are low-res — higher-res originals (~1500 px) would look better.**
- Bike size classes on the bike wrapper: `lg:-ml-[27%] lg:w-[142%]`.
